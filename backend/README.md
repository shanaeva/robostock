# NestJS Starter Kit

## Как запустить проект

Нужны Node.js 24.21+ (ветка 24 LTS), pnpm 12.18.0 и запущенный Docker.
Установить pnpm: `npm install --global pnpm@12.18.0`.
Первый запуск из корня (Linux/WSL):

```bash
# Из корня robostock
pnpm install --frozen-lockfile

# Подготовка окружения и запуск БД
cp -n .env.example .env
cp -n backend/.env.example backend/.env
docker compose up -d --wait

# Миграции и запуск бэкенда
pnpm --filter backend db:deploy
pnpm --filter backend start:dev
```

## Тестирование

**Unit-тесты** проверяют логику сервисов изолированно: обращения к БД заменены заглушками. Отдельно проверяют Zod-схемы. Запуск из `backend/`: `pnpm test`.

**E2E-тесты** проверяют контроллеры и сервисы вместе через HTTP: валидацию запросов, работу с реальной БД, ответы и ошибки API. Запуск: `pnpm run test:e2e`.

```text
Unit: Сервис → Заглушка Prisma
E2E:  HTTP → Zod → Контроллер → Сервис → Prisma → Тестовая БД
```

Для E2E: запусти PostgreSQL, скопируй `.env.test.example` в `.env.test` и укажи доступы к БД `postgres` с правом `CREATEDB`. Тестовая БД создаётся и удаляется автоматически.

## Технологии сейчас

| Технология         | Зачем нужна                                |
| ------------------ | ------------------------------------------ |
| Node.js LTS        | Среда выполнения бэкенда.                  |
| NestJS             | HTTP API, модули и внедрение зависимостей. |
| TypeScript         | Строгая типизация кода.                    |
| Zod                | Валидация запросов и настроек.             |
| PostgreSQL         | Хранение данных.                           |
| Prisma             | Типизированные запросы к БД и миграции.    |
| OpenAPI / Swagger  | Документация API.                          |
| Docker Compose     | Локальный запуск PostgreSQL.               |
| Vitest + Supertest | Unit- и E2E-тесты.                         |
| ESLint + Prettier  | Проверка качества и форматирование кода.   |
